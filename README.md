# open9527.github.io

个人主页，Hexo + [Butterfly](https://github.com/jerryc127/hexo-theme-butterfly)。

线上地址：https://open9527.github.io/

## 本地预览

```bash
npm install
npm run server
```

浏览器打开 http://localhost:4000

## 发布

源码在 `source` 分支。推送到这条分支后，GitHub Actions 会生成静态页并更新 `master`，GitHub Pages 从 `master` 发布。
